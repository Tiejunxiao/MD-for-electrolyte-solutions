(1)This MD folder contains input files for MD simulations using the DL_POLY4 software.
The "pure solvent" folder contains MD input files for pure solvent ( NaCl ).
The "SA" folder contains MD input files for NaCl solutions with spherical solutes.
The "DA" folder contains MD input files for NaCl solutions with diatomic solutes.
The "TA" folder contains MD input files for NaCl solutions with a linear triatomic solute.
The "TAb" folder contains MD input files for NaCl solutions with a nonlinear triatomic solute.
The "FA" folder contains MD input files for NaCl solutions with a linear tetraatomic solute.
The "FAb" folder contains MD input files for NaCl solutions with a nonlinear tetraatomic solute.
The "FIA" folder contains MD input files for NaCl solutions with a pentaatomic solute.

(2) This MD folder also contains fortran codes ("solvation.f90" or "solvation-key.f90") for evaluating the electric potential of a solute site.

(3) A fortran code "cavity.f90" in the "pure solvent" folder is used to generate the cavity distribution function of the pure solvent.
